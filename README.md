# Palais Lumen

Ein Casino-Spiel im Art-déco-Grandhotel für dich und deine Freunde, mit Spielgeld.

- Spielen im Browser: https://deroixdev.github.io/palais-lumen/
- Entwickeln: `npm install`, dann `npm run dev`
- Änderungen: siehe `CHANGELOG.md`

Jeder Push auf `main` baut die Web-Version neu (GitHub Actions, Workflow „Web-Version“).
